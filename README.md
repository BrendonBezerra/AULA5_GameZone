🎮 GameZone Retro

Uma página HTML simples para uma loja fictícia especializada em games clássicos e consoles retrô.

📋 Sobre o projeto

O projeto foi desenvolvido como um mini desafio de HTML, com o objetivo de praticar os principais elementos da linguagem.

A página apresenta a GameZone Retro, uma loja que oferece produtos relacionados a videogames clássicos.

🛠️ Tecnologias utilizadas
HTML5
Emojis para personalização
Links internos e externos
Imagem relacionada ao tema
✅ Elementos utilizados
Estrutura básica do HTML
Títulos e parágrafos
Texto em negrito e itálico
Lista de consoles
Link interno para a seção de produtos
Link externo para o site da Nintendo
